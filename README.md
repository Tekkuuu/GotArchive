# G.O.T Archive

A small fan-made website of G.O.T Games' anime reactions (YouTube / Patreon),
with a searchable archive and a weekly schedule.

> Unofficial fan project. Not affiliated with AniList, YouTube, or Patreon.

## Stack

- **SvelteKit 5** + TypeScript
- **PostgreSQL** + Drizzle ORM
- **better-auth**
- **Tailwind CSS 4** + daisyUI
- **AniList GraphQL**
